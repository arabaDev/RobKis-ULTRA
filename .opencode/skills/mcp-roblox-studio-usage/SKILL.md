# mcp-roblox-studio-usage

Uso do MCP do Roblox Studio para inspecionar e alterar o lugar.

**Quando usar:** Quando o MCP do Studio está conectado.

**Requer:** MCP conectado. Sem isso, pare e diga isso antes de prosseguir.

**Regras**
- Leia a hierarquia antes de editar.
- Alterações pequenas e verificadas.
- Studio precisa estar aberto com o plugin ativo.

**Verificação:** A alteração foi relida do Studio após a escrita.

**Complementares (sugeridas por similaridade):** `mcp-blender-usage`, `data-studio-api-access`, `data-memorystore-usage`

**Limites e recuperação:** Nunca simule uma ferramenta; use só o que está realmente conectado. Fora do escopo, delegue ao departamento certo. Se a verificação falhar, corrija a causa e repita; após duas falhas iguais, mude de abordagem. Marque como NÃO TESTADO o que não puder validar no ambiente.
