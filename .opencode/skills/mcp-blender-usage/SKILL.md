# mcp-blender-usage

Uso do MCP do Blender para cena, objetos e exportação.

**Quando usar:** Quando o MCP do Blender está conectado.

**Requer:** MCP conectado. Sem isso, pare e diga isso antes de prosseguir.

**Regras**
- Consulte a cena antes de criar.
- Execute código bpy em partes verificáveis.
- Blender precisa estar aberto com o addon ligado.

**Verificação:** Objetos e contagens conferidos depois da execução.

**Complementares (sugeridas por similaridade):** `mcp-roblox-studio-usage`, `data-memorystore-usage`, `mcp-fallback-manual`

**Limites e recuperação:** Nunca simule uma ferramenta; use só o que está realmente conectado. Fora do escopo, delegue ao departamento certo. Se a verificação falhar, corrija a causa e repita; após duas falhas iguais, mude de abordagem. Marque como NÃO TESTADO o que não puder validar no ambiente.
