# studio-script-workflow

Fluxo de edição de scripts e sincronização com arquivos.

**Quando usar:** Ao decidir como editar código fora do Studio.

**Requer:** Roblox Studio aberto. Sem isso, pare e diga isso antes de prosseguir.

**Regras**
- Edição no Studio é direta; sincronização com Rojo exige o projeto configurado.
- Em Team Create use rascunhos de script e publique com cuidado.
- Nunca edite o mesmo script em dois lugares ao mesmo tempo.

**Verificação:** A versão no Studio e a versão em arquivo coincidem após a sincronização.

**Complementares (sugeridas por similaridade):** `vcs-rojo-workflow`, `pipe-texture-upload-workflow`, `studio-terrain-workflow`

**Limites e recuperação:** Ações no Studio exigem o Studio aberto; sem MCP, entregue passos manuais exatos. Fora do escopo, delegue ao departamento certo. Se a verificação falhar, corrija a causa e repita; após duas falhas iguais, mude de abordagem. Marque como NÃO TESTADO o que não puder validar no ambiente.
