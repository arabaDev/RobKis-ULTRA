# game-class-system

Sistema de classes com atributos e habilidades.

**Quando usar:** Jogos de papéis.

**Requer:** Roblox Studio aberto. Sem isso, pare e diga isso antes de prosseguir.

**Regras**
- A classe é dado: atributos base e lista de habilidades.
- A troca de classe ocorre no servidor com custo e regras.
- O estado antigo é limpo.

**Verificação:** Trocar de classe aplica e remove tudo corretamente.

**Complementares (sugeridas por similaridade):** `game-ability-system`, `combat-stun-system`, `fx-music-system`

**Limites e recuperação:** Sistemas completos tocam dados salvos e economia; valide segurança e persistência antes de concluir. Fora do escopo, delegue ao departamento certo. Se a verificação falhar, corrija a causa e repita; após duas falhas iguais, mude de abordagem. Marque como NÃO TESTADO o que não puder validar no ambiente.
