# ui-accessibility-controls

Acessibilidade: contraste, tamanho e navegação por gamepad.

**Quando usar:** Interfaces para todos os jogadores.

**Requer:** Roblox Studio aberto. Sem isso, pare e diga isso antes de prosseguir.

**Regras**
- Contraste e tamanho de texto adequados.
- Selectable e GuiService.SelectedObject para navegação.
- Não use só cor para transmitir estado.

**Verificação:** Navegar a UI apenas por gamepad é possível.

**Complementares (sugeridas por similaridade):** `ui-gamepad-navigation`, `pipe-geometry-limits`, `net-player-lifecycle`

**Limites e recuperação:** Valide em pelo menos um celular e um desktop antes de concluir. Fora do escopo, delegue ao departamento certo. Se a verificação falhar, corrija a causa e repita; após duas falhas iguais, mude de abordagem. Marque como NÃO TESTADO o que não puder validar no ambiente.
